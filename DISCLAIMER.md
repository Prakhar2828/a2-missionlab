# Disclaimer

A2 MissionLab is an independent open-source educational and engineering-analysis project built from publicly available sources.

It is **not** an official NASA application, flight system, mission-operations product, or NASA-endorsed project. The project must not imply that public reconstructions reproduce internal NASA flight-control displays, procedures, flight rules, or complete telemetry.

Only public information should be committed to this repository. Do not include internal NASA screenshots, source code, documents, links, credentials, telemetry, procedures, or unpublished material.

NASA data and media remain subject to their respective source terms, attribution requirements, and usage guidance. This repository should generally store compact derived products, metadata, and reproducible ingestion scripts rather than mirroring very large source archives.

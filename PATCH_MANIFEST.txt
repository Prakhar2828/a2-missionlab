Current qualification model
- portable CI: static/evidence gates + mandatory Phase P Chromium browser gate
- local Windows release: complete protected Edge + Chrome Phase P release orchestration
- Phase Q: final adversarial review, repository-state consistency, and full requalification
- manual-only unless separately recorded: physical iPhone Safari, Android Chrome, tablet hardware, desktop Safari, real screen reader

No push, merge, release publication, or Pages deployment is performed automatically.
